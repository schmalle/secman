# Outbound domain allowlist for the Secman shielded dev container.
#
# Squid ACL type `dstdomain` syntax:
#   .example.com   matches example.com and every subdomain
#   example.com    matches that exact name only
#
# Everything not listed here (or in allowlist.local.txt) is refused with a 403
# from the proxy, and the container's iptables OUTPUT policy refuses any attempt
# to bypass the proxy. Add site-local entries to allowlist.local.txt — it is
# never overwritten by an image rebuild — or pass --allow-domain to
# scripts/container/secman-container.sh.
#
# Keep this list ordered by purpose; a bare domain with no comment is a domain
# nobody can later justify removing.
