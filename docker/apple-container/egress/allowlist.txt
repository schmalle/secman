# Outbound allowlist for the Secman shielded dev container.
#
# Enforcement is pure iptables — there is no proxy. That has one consequence you
# must keep in mind while editing this file:
#
#   *** WRITE EXACT HOSTNAMES. A LEADING DOT MEANS NOTHING HERE. ***
#
# Every name below is resolved to its A records and those addresses are what the
# firewall permits. A wildcard cannot be resolved, so `.example.com` covers
# nothing that `example.com` does not already cover. If a tool needs
# `cdn.example.com`, that exact name has to be on this list.
#
# Two line shapes are accepted:
#   host.example.com     resolved at start-up and on every refresh
#   198.51.100.0/24      an address or CIDR, used verbatim
#
# GitHub is handled separately and does not need entries here: the firewall
# fetches the published ranges from https://api.github.com/meta, which is the
# only reliable way to cover a service spread over that many addresses.
#
# Add site-local entries to allowlist.local.txt — it survives an image rebuild —
# or pass --allow-domain to scripts/container/secman-container.sh.
#
# After editing: `devctl egress refresh` (inside) or
# `./scripts/container/secman-container.sh egress refresh` (from the Mac).
